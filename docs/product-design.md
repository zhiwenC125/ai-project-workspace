# 产品与交互设计 v0.1（历史方案）

当前方案以 `flow-first-design.md` 为准。此文档保留首轮卡片中心设计，供比较。

日期：2026-10-12（Asia/Shanghai）

## 产品定位与边界

以项目、工作项和交付物为中心的 AI 研发工作台。聊天用于表达意图与处理当前上下文；项目数据、迭代、工作流和执行记录独立持久化。

首版服务个人和小团队。先接 GitHub，保留公司 CODING 平台适配接口。DeepSeek Harness 是 AI 执行底座；自研工作流引擎负责固定步骤和跨平台编排，n8n 仅作为产品体验参考。

项目画布先保留入口。项目关系图表达归属、依赖、引用；自动化工作流表达触发与执行顺序，两者不共用连线语义。

## 数据对象

Workspace → Project → Requirement → WorkItem。

Sprint 与 WorkItem 关联；工作项迁移迭代时保留需求归属。Project 可绑定多个仓库。Artifact、Conversation、Workflow、Run 均通过稳定 ID 关联项目和工作项。外部对象保存 provider、connectionId、repositoryId、externalId 和 URL。

列表、看板、画布与详情是同一组实体的视图。AI 生成的方案可转为文档或工作项，不能只留在聊天消息中。

## 三个主页面

### 项目总览

- 展示迭代工作量、待评审、阻塞和目标日期。
- 优先列出影响交付的事项；点击 WS-128 打开详情。
- 显示里程碑和最近活动；项目级 AI 面板说明当前选中的上下文。
- 项目指标来自业务数据聚合，不能直接用 AI 估计值覆盖。

### 迭代看板

- 分组：待开始、进行中、待评审、已完成。
- 卡片包含稳定编号、负责人、优先级、估算和执行摘要。
- 阻塞提示表达依赖；不强制把“阻塞”做成业务状态列。
- 演示含 12 项，其中已完成列展示 2 项并折叠 2 项。
- 未来拖拽需校验权限和状态转换，失败恢复原列并显示原因。
- 过滤和 Backlog 按钮当前为视觉设计；未接入可操作数据。

### 工作项与 AI 执行

- 固定展示需求、验收标准、负责人、迭代、外部资源。
- 执行区展示步骤、时间、检查结果与产物。
- 用户可查看改动、要求修改、继续讨论；实现时这些操作必须挂在当前工作项和具体执行上。
- AI 已产出 PR 并不代表工作项完成，团队权限场景仍需人工验收。

## 状态与交互约定

| 场景 | 可见信息 | 恢复/下一步 |
| --- | --- | --- |
| 未绑定仓库 | 尚未连接，需求管理仍可使用 | 配置连接 |
| 运行中 | 当前步骤、最近事件、耗时 | 取消当前运行；是否支持取决于执行器能力 |
| 待人工处理 | 等待原因、相关产物、处理人 | 评审、反馈或恢复执行 |
| 执行失败 | 失败步骤、已完成步骤、错误摘要 | 仅重试失败步骤 |
| 执行器离线 | 最近联系时间，保留运行记录 | 重新连接后核对运行状态 |
| 外部写入结果未知 | 不显示成功，也不直接重复创建 | 先查询远端确认结果 |

业务状态：todo / in_progress / in_review / done。
执行状态：queued / running / waiting_for_human / succeeded / failed / cancelled。
阻塞作为依赖关系及原因单独记录。执行成功只能促使系统重新评估业务状态，不能直接完成验收。

## 界面规范

- 桌面主画板：1600 × 1000。
- 左侧导航：232 px；右侧上下文面板：320 px；工作区间距 24 px。
- 中文字体：Noto Sans SC；字号 11、12、14、17、28、30 px。
- 主色靛蓝，成功绿色，需处理琥珀色，失败红色；均同时使用文字。
- Figma 具有 49 个变量（18 个原色、18 个语义色、9 个间距、4 个圆角）和 7 个文字样式。
- 组件：Button 5 个样式、Status 5 个状态、Navigation 2 个状态、TaskCard。
- 使用 Auto Layout、组件实例和可编辑文字。设计系统搜索发现通用社区库，但导入因工具响应超限未提交；本轮建立项目本地组件，统一中文排版与状态语义。

## 响应式实施建议（未绘制额外画板）

1440 px 以下将右栏改为可展开侧栏；1280 px 以下允许收起项目导航。看板保持卡片最低可读宽度，使用横向滚动。移动端不属于本轮范围。

## 验证与限制

五个交付画板已完成截图检查；结构检查未发现子元素超出容器，所有文字使用 Noto Sans SC，无整页截图图层。三个主页面和状态页配置 19 个跨画板导航交互。

本轮不包含新建工作项表单、真实搜索筛选、拖拽逻辑、真实授权、任务执行、聊天发送或 PR 跳转。它们是下一阶段实现内容。没有声称通过端到端运行测试。
